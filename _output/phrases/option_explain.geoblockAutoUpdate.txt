A weekly cron task downloads the latest GeoLite2 database using the license key above. Turn this off to manage updates yourself - from an external cron task running the geoblock:update-database command, or by any other means - in which case no license key is needed here and none will be reported as missing. An out-of-date database still answers lookups, using stale data, so geoblock:validate warns when it ages regardless of how it is updated.
